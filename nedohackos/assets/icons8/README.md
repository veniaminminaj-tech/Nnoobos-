# NedohackOS — original pixel-art icon set

These eight icons are original artwork made for the NedohackOS desktop concept, not copied from the linked iStock preview.

## Icons
- `computer.svg` — Computer
- `folder.svg` — Folder / file manager
- `text-file.svg` — Text document
- `trash.svg` — Trash
- `terminal.svg` — Terminal
- `settings.svg` — Settings
- `browser.svg` — Browser
- `app-grid.svg` — Applications menu

## Resolution and style
Each SVG has a 256×256 viewBox and explicit 256×256 dimensions. They are resolution-independent vector images that can be rasterized at 256×256 pixels or scaled down for desktop use. The artwork keeps a crisp pixel-art aesthetic with a coordinated blue, gold, and mint palette. The term “256×256” describes the canvas size; these are not 256-bit files.

## Integration status
The artwork assets are committed to the `nedohackos-kolibri` branch and staged by the source-patch workflow. They do not yet replace KolibriOS's built-in desktop icons or automatically set the wallpaper in a bootable image. Native desktop integration requires confirming the target desktop/icon format in the pinned KolibriOS source.
