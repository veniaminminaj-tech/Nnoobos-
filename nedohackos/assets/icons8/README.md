# NedohackOS — original 8-bit icon set

These are original, simple pixel-art SVG icons created for the NedohackOS desktop concept. They are not copied from the linked iStock preview.

## Icons
- `computer.svg` — Computer
- `folder.svg` — Folder / file manager
- `text-file.svg` — Text document
- `trash.svg` — Trash
- `terminal.svg` — Terminal
- `settings.svg` — Settings
- `browser.svg` — Browser
- `app-grid.svg` — Applications menu

## Rendering
Each icon uses a 16×16 viewBox and `shape-rendering="crispEdges"` to preserve hard pixel edges. SVGs can be previewed in a browser and converted to PNG at 16×16, 32×32, or 48×48 if the KolibriOS desktop integration needs bitmap assets.

## Integration status
This commit adds the artwork assets only. It does not yet replace KolibriOS's built-in desktop icons or change the bootable image. Integrate them after confirming the target desktop/icon format in the pinned KolibriOS source.
