# Desktop icon resources

The project uses the open-source [Lucide icon set](https://lucide.dev/icons/) as its reference library. Lucide SVG icons are licensed under the ISC License; see the [official license](https://github.com/lucide-icons/lucide/blob/main/LICENSE).

Icon pages used as references:
- [Code](https://lucide.dev/icons/code-xml)
- [Globe](https://lucide.dev/icons/globe)
- [Folder](https://lucide.dev/icons/folder)
- [Info](https://lucide.dev/icons/info)
- [Terminal](https://lucide.dev/icons/terminal)

The current Tkinter desktop uses text/emoji fallbacks for compatibility with a standard Python install; SVG assets are intended for later native desktop rendering.
